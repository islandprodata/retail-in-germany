## Fields

| Column | Description | Example |
|---|---|---|
| `country` | Country (all rows: `germany`) | `germany` |
| `founded` | Year founded (may be empty) | `1998` |
| `id` | Opaque source record ID | `veTDODnUBWiBtTBOPzhB5QFaRPlK` |
| `industry` | Industry (all rows: `retail`) | `retail` |
| `linkedin_url` | LinkedIn company page (domain + path) | `linkedin.com/company/pelzhaus-plappert` |
| `locality` | City / town | `mannheim` |
| `name` | Company name | `pelzhaus plappert` |
| `region` | State / region (lowercase) | `baden-württemberg` |
| `size` | Employee-count band | `11-50` |
| `website` | Company website domain (may be empty) | `plappert.de` |

**Notes:**
- `founded` and `website` are empty for some records.
- `size` values look like `1-10`, `11-50`, `51-200`, etc.
- CSV is UTF-8 with a header row; fields with commas are quoted.
